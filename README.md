# 🏨 Hotel Premier - Digital QR Menu Display & Live CMS
**Pride Pure Veg AC Restaurant, Bhusawal**

A mobile-first, zero-friction **Digital QR Menu Display** web application built specifically for **Hotel Premier, Bhusawal**.

---

## 🌟 Key Features

### 1. 🌐 Multilingual Support (English, Hindi, Marathi)
- **1-Tap Language Switcher**: Easily switch between **English (EN)**, **Hindi (हिंदी)**, and **Marathi (मराठी)** right in the top header.
- **Full Dynamic Translation**: UI labels, category titles, section subtitles, descriptions, filters, badges, terms & conditions, and footer update instantaneously.
- **Language Preference Memory**: Remembers customer language choice across visits.

### 2. 📲 Category-First Frictionless Menu Display
- **Scan QR ➔ Home View**: Opens immediately to the visual category grid with all **19 Menu Sections** (with Hindi & Marathi subtitles like *शाही पनीर स्पेशल*, *तंदूर कबाब*, *सकाळचा नाश्ता*, dish counts, and cover photos).
- **Click Section ➔ View Dishes**: Tapping any section displays that category's dishes with a prominent sticky **`⬅️ All Sections`** button for effortless return.
- **Senior Citizen Text Size Mode (`A+` / `A-`)**: 1-tap font size zoom toggle in header for high readability.
- **Pure Display (No Direct Ordering Overhead)**: Pure, lightning-fast digital menu viewing with no cart, signup, or app download.
- **Live Search & Quick Filters**: Search any dish (e.g., *"paneer"*, *"khandeshi"*, *"chai"*, *"pasta"*) or filter by *Chef's Special 👑*, *Bestsellers 🔥*, *Khandeshi Special 🌶️*, or *Under ₹150 💰*.

### 3. 🎨 Authentic Menu Theme & Color Palette
- **Color Palette**: Warm Terracotta (`#4A230D` / `#6C3516`), Saffron Mustard Gold (`#D4901C` / `#F7C860`), and Cream Parchment (`#FAF5EA` / `#FFFDF9`).
- **Typography**: Google Fonts (*Playfair Display*, *Cinzel*, *Plus Jakarta Sans*, *Tiro Devanagari*).
- **Official Crest & Badges**: Flying birds vector crest + Pride Pure Veg Red/Green badges.
- **Terms & Conditions**: Official Page 8 Terms (5% GST, 20-min fresh preparation notice, admission reserved).

### 3. ⚙️ Staff Menu Manager & Image Studio (PIN: `admin123`)
- **📷 Image Replacement Provision**:
  - Upload photos from smartphone camera, phone gallery, or PC.
  - Paste any web image URL.
  - Choose from 16 curated high-definition Pure Veg dish presets.
- **🍔 Live Pricing & Availability**: Instant inline price edits and 1-tap "Sold Out / Available" toggles.
- **📲 Table QR Studio**: Generate customized QR codes for Table 1 to 20+ with 1-click printable table standees.
- **💾 Backup & Reset**: Export/import JSON backups or 1-click reset to official PDF defaults.

## 🚀 1-Minute Live Deployment Options

### Option A: Deploy to Netlify
1. Go to [netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the `hotel-premier-qr-menu` folder.
3. Your website is live worldwide with free HTTPS and global CDN.

### Option B: Deploy to Vercel
1. Go to [vercel.com](https://vercel.com).
2. Drag and drop the `hotel-premier-qr-menu` folder or connect via GitHub.
3. Your live URL will be generated instantly (e.g. `https://hotel-premier-menu.vercel.app`).

### Option C: GitHub Pages
1. Push the folder to GitHub.
2. Go to **Settings > Pages > Branch: main / root**.
3. Your site will be available at `https://<username>.github.io/<repo-name>/`.
